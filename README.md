# C Programming Practice

A topic-wise collection of C programs for learning, revision, and college practical practice.

## Topics
- Basics and operators
- Conditional statements
- Loops and number programs
- Pattern printing
- Functions and recursion
- Arrays and matrices
- Strings
- Pointers
- Structures and unions
- File handling
- Dynamic memory allocation
- Data structures

## Compile and run

Install a C compiler such as GCC. From a terminal in the folder containing a program:

```bash
gcc filename.c -o program
```

On Windows, run:

```bash
program.exe
```

On Linux/macOS, run:

```bash
./program
```

Each `.c` file contains a separate `main()` function, so compile one program at a time.

## Notes
- These are learning examples. Read and test each program before using it.
- Binary search expects a sorted array.
- Input sizes are kept small for beginner-friendly examples.
- Some advanced examples (linked list, stack, queue, dynamic memory) are included for practice.
